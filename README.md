## 📋 系統需求

在另一台電腦使用前，請先確認以下軟體是否已安裝：

| 軟體 | 最低版本 | 下載網址 |
| :--- | :--- | :--- |
| **Node.js** | 18.x 以上（建議 LTS 版） | https://nodejs.org |

> ✅ Node.js 安裝後會自動附帶 `npm`，無需另外安裝。

---

## 🚀 在新電腦上快速啟動

### 步驟一：安裝相依套件（**只需執行一次**）

打開「命令提示字元 (CMD)」或「PowerShell」，切換至本資料夾後執行：

```bash
cd 115class
npm install
```

> 這一步會自動下載 `express` 與 `socket.io` 兩個套件（約 1~2 分鐘，需要連網）。  
> 完成後資料夾內會出現 `node_modules` 目錄，之後不需要重複執行。

---

### 步驟二：啟動伺服器

**方式一：雙擊啟動（推薦）**

直接雙擊資料夾內的 `start.bat` 即可。

**方式二：命令列啟動**

```bash
npm start
```

**啟動成功** 後，命令列視窗會顯示：

```
====================================================
   classroom Binary Game Server is running!
   本地瀏覽器網址: http://localhost:3000
====================================================
```

---

### 步驟三：開啟瀏覽器

| 身分 | 網址 | 帳號 | 密碼 |
| :--- | :--- | :--- | :--- |
| **教師端（主控大螢幕）** | `http://localhost:3000/teacher.html` | `t01` | `t01` |
| **學生端（闖關遊戲）** | `http://localhost:3000/student.html` | `s01` ~ `s30` | 無需密碼 |

## 🏫 電腦教室多人連線設定

若要讓**全班學生同時連線**（例如在電腦教室），請將教師電腦的**區域網路 IP**告知學生，學生以瀏覽器開啟即可。

### 查詢教師機 IP 的方法：

1. 按 `Win + R`，輸入 `cmd`，按 Enter
2. 輸入 `ipconfig`，按 Enter
3. 找到 **「IPv4 位址」**，例如 `192.168.1.100`

### 學生連線網址格式：

```
http://[教師機的 IPv4 位址]:3000/student.html

範例：http://192.168.1.100:3000/student.html
```

> ⚠️ **注意**：學生與教師電腦必須連接同一個 Wi-Fi 或區域網路（LAN）才能正常連線。

## 🎮 課堂使用流程 (SOP)

```
1. 教師電腦執行 start.bat 啟動伺服器
2. 教師瀏覽器開啟 teacher.html → 登入 t01 / t01
3. 設定班級人數與組別數量 → 點擊「隨機分組」
4. 將學生連線網址投影在黑板（或以口頭告知）
5. 學生在各自電腦或平板開啟 student.html → 選擇學號登入
6. 確認大多數學生已在等待室後 → 教師點擊「遊戲開始」
7. 課堂進行中：大螢幕即時顯示各組二進位分數，可隨時暫停提問：
     「第 X 組的分數是 1011，請問十進位是幾分？」
8. 任一組答對後 → 點擊「顯示答案 (十進位)」驗證
9. 遊戲結束後點擊「重置分數」即可重新開始下一輪
```

## ❓ 常見問題排除

### Q1：雙擊 `start.bat` 出現「連接埠已被使用」錯誤？
> 伺服器可能已在背景運作，直接開啟瀏覽器前往 `http://localhost:3000` 即可使用。若確認需要重啟，請先在工作管理員中結束 `node.exe` 程序，再重新執行 `start.bat`。

### Q2：`npm install` 卡住或速度很慢？
> 可能是網路問題，請確認電腦已連上網路，或等待幾分鐘讓下載完成。

### Q3：學生連不上教師的伺服器？
> 請確認：  
> ① 學生輸入的 IP 是否正確（用 `ipconfig` 再次確認）  
> ② 教師電腦的防火牆是否封鎖了 Port 3000  
> ③ 學生與教師是否在同一個網路環境

### Q4：瀏覽器出現畫面後學生分組沒更新？
> 請重整瀏覽器（按 F5），或確認網路連線穩定。

## 📦 搬移到新電腦的注意事項

複製到新電腦時，請確認以下兩種情況：

| 情況 | 需要的操作 |
| :--- | :--- |
| **連同 `node_modules` 一起複製** | 直接執行 `start.bat` 即可，不需要重新安裝 |
| **只複製原始碼（不含 `node_modules`）** | 先執行 `npm install` 安裝套件，再執行 `start.bat` |

> 💡 建議搬移時**不包含 `node_modules`**（此資料夾體積龐大），在新電腦上重新執行 `npm install` 即可重建，速度快又乾淨。
